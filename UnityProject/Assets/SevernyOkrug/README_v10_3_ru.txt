СЕВЕРНЫЙ ОКРУГ — обновление v10.3: починка после v06.2 + иконка игры
====================================================================

ЧТО СЛУЧИЛОСЬ
Пакет v06.2 (иконка) старый. В нём лежат версии ProceduralAudio.cs и
SevernyBuild.cs от v06. При импорте они заменили новые файлы. С v08 звук
разделён на две части (ProceduralAudio.cs + AmbientAudio.cs), а старый файл
об этом не знает. Отсюда ошибка CS0260, и Unity не может собрать ни один
скрипт, поэтому «перестало работать всё».

ЧТО В ПАКЕТЕ
- ProceduralAudio.cs и SevernyBuild.cs: возвращены текущие версии.
  Ошибка CS0260 уходит, сборка .exe снова работает как в v09+.
- Иконка игры (компас над ночным городом): Icon/SevernyOkrug_Icon.png
  (1024 px) и упрощённый вариант для мелких размеров (16–48 px).
  Ставится сама после импорта, если в проекте нет другой иконки, и перед
  каждой сборкой через Severny > 6. Поставить принудительно:
  Severny > Apply Game Icon.
- Всё из v10.2 (исправление рук от первого лица), если его ещё не ставил.

УСТАНОВКА (поверх v10.1, v10.2 или «сломанного» проекта после v06.2)
1. Выйди из Play Mode.
2. Assets > Import Package > Custom Package… >
   SevernyOkrug_v10_3_update.unitypackage > Import (всё отмечено).
3. Дождись компиляции. Красных ошибок в Console быть не должно, появится
   строка «[Severny] Game icon applied».
4. Пересобери .exe: Severny > 6 Build Windows. Иконка будет у .exe,
   у окна игры и на панели задач.

ВАЖНО: не импортируй старые пакеты (v04–v06.x) поверх новой версии, они
возвращают старые файлы. Всё нужное из них уже есть в новых пакетах.

Если проводник Windows показывает у .exe старую иконку, это кеш иконок
Windows. Перемести .exe в другую папку или перезапусти проводник.

ПРОВЕРЕНО
- Ошибку воспроизвёл: старый ProceduralAudio.cs поверх текущих скриптов
  даёт ровно CS0260 (9,25).
- С файлами из этого пакета всё компилируется для Unity 6000.0 и 6000.6
  (игра и редактор).
