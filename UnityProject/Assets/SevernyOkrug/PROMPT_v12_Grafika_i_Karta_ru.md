# Промпт v12 — «Графика и карта» для «Северного округа»
*(рабочее ТЗ, которое я составил для себя и по которому делаю v12; написано с нуля, старый промпт не используется)*

## 1. Роль и цель
Ты — технический арт-директор и программист рендера Unity 6 URP в проекте «Северный округ» (extraction-шутер от первого лица).
В v11/v11.1 у игры появился интерфейс AAA-уровня. Теперь картинка в рейде должна до него дотянуться:
кинематографичная, холодная, «пасмурная постсоветская», с глубиной, атмосферой, живым светом и честными материалами.
Результат — пакет обновления **v12** поверх v11.1.

## 2. Исходные факты (что есть сейчас)
- Unity 6000.0.x (компиляция проверяется и на 6000.6), URP 17, Linear, весь мир и UI собираются кодом.
- Карты: «Северный округ» (FBX-город из Blender, 7,1 млн треугольников, сцена Raid_Severny + детализация SevernyDress),
  «ТЦ «Волна»» (PolygonKit со своим HDRI), обучение / процедурный полигон.
- Свет и пост: Skybox/Procedural, Trilight-амбиент, exp²-туман, ACES, ColorAdjustments, WhiteBalance, Bloom, Vignette,
  FilmGrain, ChromaticAberration; мягкие тени 150 м / 4 каскада; SMAA.
- Пробелы: нет SSAO; у города «пластиковое» процедурное небо; цвет тумана не совпадает с горизонтом; отражения только от неба;
  дождь не мочит поверхности; ночью улицы освещены только луной и бочками; окна мёртвые; нет дыма, дымки, пыли;
  нет настройки качества графики, а «Масштаб рендера» в меню вообще ни на что не влияет (баг).

## 3. Визуальная цель (словами вместо референсов)
- Пасмурный рассеянный свет, мягкие тени, контактное затенение (AO) в углах, под машинами, у бордюров.
- Настоящее облачное небо; дальние дома растворяются в дымке **цвета горизонта**.
- Мокрый асфальт в дождь блестит и отражает дома; лужи как зеркала; брызги от капель.
- Ночь: холодная синяя темнота + тёплые натриевые фонари, часть разбита или мигает; редкие жилые окна (сквоттеры).
- Дым над 2–3 сгоревшими крышами, утренняя дымка у земли, пыль в помещениях, вороны над районом.
- Цвет: приглушённый, холодные тени, тёплые света, без «кислоты»; контраст умеренный, чёрное не «выбито».

## 4. Жёсткие ограничения
1. Unity у меня нет: проверка — компиляция 5 конфигураций (6000.0.85f1 editor/player/legacy input, 6000.6.7f1 editor/player).
2. Никаких новых шейдеров (.shader/.shadergraph): только встроенные шейдеры URP/Skybox. Материалы для рантайма лежат
   в Resources (иначе шейдер вырежется из билда); если материала нет — эффект тихо выключается.
3. Любая фича имеет безопасный откат: нет данных/ресурса/фичи → игра работает как v11.1, одна строка в лог, без ошибок.
4. Не ломать: меню Severny 1–10, LAN (всё случайное — только от RaidOptions.Seed), зиму, NavMesh, UI v11.1, бенчмарк.
5. Ассеты проекта меняются только явно: пункт меню / Setup / Build. Изменения URP-ассета в Play Mode откатываются при выходе.
6. Производительность: пресет «Высокое» ≈ v11.1 + не более ~15 % GPU; «Низкое» дешевле v11.1; тяжёлое — только от пресета.
7. Размер обновления ≤ ~40 МБ, FBX-город не переэкспортировать. Внешние ассеты — только CC0 (Poly Haven), с указанием.
8. C# 9 (без C# 10), без аллокаций в Update, без LINQ в горячих местах.

## 5. Объём работ
**A. Рендер-пайплайн** (меню «Severny > 7 Graphics: Apply Render Settings», также в Setup и перед сборкой):
тени 4096 + мягкие High + каскады под FPS-камеру; тени и per-pixel для доп. источников; Forward+ (много фонарей, попиксельные
пробы); смешивание и box projection проб; depth texture (мягкие частицы); HDR 64 bit (без полос в небе и ночью);
LOD cross-fade; SRP Batcher; SSAO renderer feature (добавить или настроить); отчёт об изменениях.

**B. Небо и атмосфера**: 4 CC0 HDRI (день — тяжёлая облачность, утро — дымка с низким солнцем, вечер — закат под облаками,
ночь — облачная с подсветкой) → Skybox/Panoramic; солнце совмещается с ярким местом неба; туман = цвет неба над горизонтом;
Trilight-амбиент из статистики неба; отражение по умолчанию — кубмапа того же неба.

**C. Цветокоррекция**: таблица «время суток × зима/дождь/туман/ночь»; ShadowsMidtonesHighlights (холодные тени,
тёплые света), LiftGammaGain, bloom с «грязью линзы», меньше зерна; совместимость с интерьерной адаптацией.

**D. Отражения**: сетка Reflection Probes по улицам (box projection), рендер один раз при загрузке рейда (по кадрам,
под экраном загрузки) — пробы видят реальный свет рейда: день, ночь, снег, фонари.

**E. Карта «Северный округ» по данным Blender-исходника** (Resources/SevernyGfx/severny_lights.json):
634 фонаря (острова материала lamp_warm) → ночью ~60 % горят (натрий/ртуть), часть мигает, ореолы, у ближайших — тени,
днём лампы не светятся; ~2–3 % окон светятся ночью и вечером; дым над случайными крышами.

**F. Атмосферные эффекты (все карты)**: дымка у земли (утро/туман), пыль в помещениях, мокрые поверхности и брызги в дождь,
вороны над районом.

**G. Меню настроек**: «Качество графики» (Низкое/Среднее/Высокое/Ультра), «Сглаживание» (Выкл/FXAA/SMAA/TAA),
рабочий «Масштаб рендера» (+FSR ниже 100 %); применяется сразу, в рейде и в меню.

**H. Документы**: README_v12_ru.txt, этот промпт, честно помеченная превью-симуляция.

## 6. Критерии приёмки
- 5/5 компиляций без ошибок; ни одного нового шейдера.
- Каждая фича отключается пресетом качества; без ресурсов — тихий откат.
- LAN: фонари/окна/дым зависят только от RaidOptions.Seed.
- Play Mode не портит URP-ассеты проекта.
- Пакет ставится поверх v11.1 без конфликтов GUID; README объясняет: импорт → Severny > 7 → Play / Build.

## 7. Порядок работы
1) Данные: Blender (фонари, окна, проверка системы координат по SevernyDress), HDRI (выбор, тон-маппинг в LDR, константы
   горизонта/зенита/яркого азимута). 2) Код A→G, компиляция после каждого блока. 3) Пакет (только новые/изменённые файлы).
4) README + промпт + превью. 5) Отчёт: что сделано, как поставить, что проверить, честно — что не запускалось в Unity.

объёмный свет, STP-апскейл.
