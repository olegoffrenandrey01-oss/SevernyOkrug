СЕВЕРНЫЙ ОКРУГ — обновление v11: новый интерфейс
=================================================

ЧТО В ПАКЕТЕ
Весь интерфейс перерисован в одном стиле: тёмный графит, чёрный, оливковый,
приглушённые янтарные, оранжевые и красные акценты. Логика игры, предметы,
цены, сохранения, сеть, горячие клавиши и события кнопок не менялись.
Профиль и схрон сохраняются.

ПО ЭКРАНАМ
- Главное меню: фон — рендер карты ТЦ «Волна», логотип, нумерованное меню,
  карточка оператора (уровень, деньги, рейды, выживаемость), подсказки клавиш.
- Подготовка к рейду: карточки локаций с картинкой (время, противники),
  условия рейда переключателями (противники, время суток, погода, сезон),
  сводка снаряжения.
- Загрузка: арт локации, совет, полоса прогресса.
- Настройки: группы «Управление», «Изображение», «Звук», «Графика»,
  переключатели со шкалой, совет по FPS.
- Персонаж (раньше «База»): досье, деньги, исходы рейдов, статистика
  плитками, список управления.
- Игра по сети (LAN): позывной, создание и поиск игр, список игроков,
  справка.
- Снаряжение, схрон, скупщик: слоты с силуэтами, 3D-иконки предметов, рамки
  редкости, подсказка при наведении (характеристики, вес, цена).
  При перетаскивании места подсвечиваются: зелёный — можно, красный —
  нельзя, янтарный — объединить. Карточка выбранного предмета с кнопками
  действий, вес и стоимость снаряжения, занятость схрона. У скупщика —
  фильтры по категориям, цена подсвечивается, если денег не хватает,
  продажа перетаскиванием на список или Ctrl+клик.
- Инвентарь в рейде: то же плюс ящик с поиском, зона «Земля», здоровье по
  частям тела с эффектами. Новое: часы рейда в верхней панели (последние
  5 минут — красным).
- HUD: силуэт здоровья, оружие и патроны, уведомления, выходы и время,
  прогресс аптечки, подсказка взаимодействия, таймер эвакуации.
- Пауза, окна подтверждения, итоги рейда (ВЫЖИЛ / ПОГИБ), карточка шага
  обучения с прогрессом.

ТЕХНИЧЕСКОЕ
- Шрифты: Oswald (заголовки), Fira Sans Condensed (текст), IBM Plex Mono
  (цифры). Лицензия SIL Open Font License, файлы лицензий лежат рядом:
  Resources/SevernyUI/Fonts/*_LICENSE_OFL.txt.
- Иконки: атласы Resources/SevernyUI/ui_glyphs.png (значки) и
  item_icons.png (предметы).
- Масштабирование: 1920×1080, режим Expand. На 21:9, 16:10 и 5:4 ничего не
  обрезается.
- Настройки импорта UI-текстур ставятся сами после импорта
  (Editor/SevernyUIImport.cs: без растяжения до степени двойки, без сжатия
  значков). Вручную: Severny > UI: Fix Texture Import.
- Изменённые файлы: Scripts/UI/* (UIFactory, UIManager*, InventoryUI,
  GridView), Scripts/Raid/Tutorial.cs (только оформление подсказок).
  Новые: Scripts/UI/UITheme.cs, UIAssets.cs, UIAnim.cs, UITracking.cs,
  Editor/SevernyUIImport.cs, Resources/SevernyUI/* (шрифты, атласы, арт).

УСТАНОВКА (поверх v10.3 или v10.3 FULL)
1. Сделай копию проекта или коммит. Выйди из Play Mode.
2. Assets > Import Package > Custom Package… >
   SevernyOkrug_v11_UI_update.unitypackage > Import (всё отмечено).
3. Дождись компиляции. Красных ошибок в Console быть не должно. Один раз
   появится строка «[Severny] UI texture import settings fixed …».
4. Запусти сцену Main или пересобери .exe: Severny > 6 Build Windows.
Для нового пустого проекта есть SevernyOkrug_v11_FULL.unitypackage
(всё из v10.3 FULL плюс этот интерфейс).

ПРОВЕРЕНО
- Компиляция для Unity 6000.0 и 6000.6 (игра, редактор, старая система
  ввода): без ошибок.
- Все экраны отрисованы в тестовом стенде на 1920×1080, 2560×1080,
  1920×1200 и 1280×1024.
- В самом Unity не запускалось. Если что-то выглядит не так, пришли
  скриншот.
